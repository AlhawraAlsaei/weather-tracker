# Weather Tracker

A weather tracking application developed using Python, Pandas, and Streamlit as part of the Data Science Bootcamp.

## Live Application

https://alhawra-weather-tracker.streamlit.app

## Project Overview

Weather Tracker is an interactive web application that allows users to record, manage, search, and analyze weather observations.

## Features

- **Log Observation:** Record the date, temperature, weather conditions, humidity, and wind speed.
- **Dashboard (Stats):** Display average, minimum, and maximum temperatures, temperature trends, and weather insights.
- **Search:** Find weather observations by date.
- **View All Data:** View and edit recorded weather observations.
- **CSV Support:** Upload existing weather data and download observations as a CSV file.

## Technologies Used

- Python
- Pandas
- Streamlit

## Project Files

- `app.py` – Main Streamlit application.
- `myutils.py` – Functions for temperature statistics and date filtering.
- `weather_data.csv` – Sample weather observations.
- `requirements.txt` – Required Python libraries.

## How to Run Locally

1. Download or clone this GitHub repository.
2. Install the required libraries:

   `pip install -r requirements.txt`

3. Run the application:

   `streamlit run app.py`

4. Open the application in your browser.
